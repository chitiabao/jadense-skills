# Jadense Skills

Provider-neutral scholarly literature search skills for AI agents. Normalizes results from arXiv, OpenAlex, Crossref, PubMed, Semantic Scholar, and Google Scholar into a unified interface with bilingual (Chinese + English) delivery.

面向 AI 代理的提供者中立学术文献搜索技能。将来自 arXiv、OpenAlex、Crossref、PubMed、Semantic Scholar 和 Google Scholar 的结果标准化为统一接口，支持中英双语交付。
