# 中文学术 PPT 核心规范

> 本文件是 `jadense-ppt-master` 的常驻学术约束。Default Generate、Quick
> Generate 与 Beautify 在进入各自流程时都必须完整读取并持续应用；它不替代
> 原有 Gate、CLI、schema、SVG 或 OOXML 契约。

## 1. 适用范围与优先级

出现“开题、课题、中期、预答辩、答辩、学术会议、组会、论文汇报、项目评审、
基金评审、研究报告”等语义，或材料本身明显属于科研/高校场景，即视为学术任务，
并按需读取 [`academic-report-types.md`](./academic-report-types.md)。报告类型不明确但
不会改变关键结构时，按材料最接近的类型继续；会改变必需章节、证据口径或时间分配
时，Default 合并成一次澄清，Quick 选择最保守的“通用学术报告”并显式记录该假设。

学术任务的决策优先级：

1. 用户明确要求与院校、学位点、会议、项目主管部门的强制模板；
2. 当前路由的保真边界（例如 Beautify 的逐字、1:1 约束）；
3. 用户提供材料、原始数据和可核验来源；
4. 本文件与对应报告类型规范；
5. 视觉风格偏好。

强制模板可以改变画布、章节名、页序、校徽位置和字号，但不能授权虚构、误引、
夸大或隐藏重要限定。明确的非学术请求仍可使用原有商业/艺术能力；艺术化、营销化
或娱乐化表达不得由系统自行套用到学术任务。

## 2. 学术项目事实

学术任务在规划前解析并持续保留下列信息。Default 写入 `design_spec.md §I Project
Information`；Quick 只保留在当前活动上下文；Beautify 从源文件和用户要求中读取，
不得据此改写冻结内容。

| 项目事实 | 内容 |
| --- | --- |
| 报告类型 | 开题 / 中期 / 预答辩 / 正式答辩 / 学术会议 / 组会 / 项目评审 / 基金评审 / 通用学术报告 |
| 学科与主题 | 一级/二级学科、研究方向、题目及必要术语 |
| 培养阶段 | 本科 / 硕士 / 博士 / 博后 / 教师或项目团队；不适用时写“不适用” |
| 院校或会议 | 院校、学院、学位点、会议或评审组织；未知时不得编造 |
| 听众 | 导师、答辩委员、领域同行、跨学科听众、项目专家等 |
| 时长 | 总时长及提问是否另计；未知时只给可调整的估计 |
| 强制章节 | 用户或模板要求的章节、顺序、封面字段和致谢要求 |
| 引用格式 | 用户/机构指定格式；否则采用页内短引 + 备注完整来源 |
| 证据状态 | 已核验 / 用户提供未外部核验 / 推导 / 演示或情景数据 / 待补证据 |

所有用户可见的建议、摘要和解释默认使用简体中文。程序字段、命令、schema、枚举、
公式与标准缩写保持原有英文标识；首次出现的非通用英文缩写给出中文释义。

## 3. 论证与证据底线

**正式与准确优先于艺术性。** 每页先确定它在学术论证中的职责：问题、证据、方法、
结果、限制、贡献或请求；视觉只负责降低理解成本，不得制造“看起来像结论”的证据。

- 不得虚构论文、作者、期刊、DOI、数据集、样本量、实验结果、基线、显著性、政策、
  机构结论、伦理批准或引用页码。无法核验时写“待核验/待补充”，不得补一个像真的值。
- 区分“来源直接报告”“基于来源的推导”“作者/汇报者解释”“演示或情景数据”。观察、
  结果和解释分开表达；相关性不得写成因果，未完成工作不得写成既成成果。
- 外部事实只使用实际读取且支持该措辞的来源。页内短引与备注完整来源必须指向同一
  证据；不得用只支持相邻主题的文献装饰性背书。
- 用户提供的数据可以直接使用，但标记为“用户提供，未独立核验”，除非已完成核验。
  计算得到的派生值注明公式、输入与“据所给数据计算”，并复核量纲。
- 演示、模拟、合成、占位或情景数据必须在图表/表格邻近位置醒目标注“演示数据”或
  “情景数据”，备注再次说明；不得与真实研究结果混排而不区分。
- 学术争议保留适用范围、相反证据和主要限制。不得把“创新点”写成未经比较的口号；
  应说明相对哪个已知基线、解决何种缺口、证据目前处于什么阶段。

### 3.1 统计表达

- 保留样本量 `n`、分析单位、分母、时间窗、单位、数据集版本、随机种子和重复次数等
  影响解释的条件；来源没有提供时不补写。
- 来源提供误差线、置信区间、标准差/标准误时必须保留并准确命名。未提供不确定性时，
  不得自行画出貌似可信的误差线。
- 只有来源明确给出检验方法与结果时才能写“显著”。同时保留必要的统计量、自由度、
  `p` 值、效应量或置信区间；“趋势”“提高”“优于”不能偷换为显著性结论。
- 比较必须说明基线与口径。不得通过截断坐标轴、面积编码、双轴错配或挑选时间区间
  放大差异；确需非零起点或轴断裂时必须醒目标注并说明原因。

## 4. 引用与备注

学术页采用“页内短引 + 备注完整来源”的双层做法，院校/会议模板另有强制格式时
从其规定。

- 页内短引靠近对应论断、图、表或公式，可用“作者/机构，年份”或编号制；同一套稿件
  只用一种主格式。图表还需题注与来源行，来源不能只埋在最后一页。
- 外部图片、复用论文图、数据集、软件、标准和网页均记录来源与许可/使用依据；“来自
  网络”不是来源。
- 普通学术讲者备注在每页正文后写一个完整来源块；即使本页无外部来源，也明确说明
  是封面、结构页、用户材料或演示数据。格式：

```markdown
[Sources]
- [S1] 作者/机构. 题名. 期刊/会议/发布方, 年份. DOI 或稳定 URL. 本页支持：<具体论断/图表>。
- [S2] User-supplied: <文件名>, <页码/工作表/区段>. 未独立核验。
[/Sources]
```

- 不得列入本页未实际使用的来源，不得只给搜索结果页、二手聚合页或无法定位的主页。
- `notes_to_audio.py` 会逐字朗读备注正文。启用 Narration Audio 时，讲稿保持纯口语，
  不把非口播 `[Sources]` 块塞入音频输入；完整来源改由页内来源、参考文献/附录页和
  项目来源工件共同承担。未启用音频的普通学术 PPT 则保留上述备注来源块。

## 5. 学术视觉语言

默认采用 `academic-research` **Style**；它与 `visual_style` 枚举是两个独立轴。
`visual_style` 只从 `swiss-minimal`、`editorial`、`data-journalism`、`blueprint`
选择与学科相符的基础（或基于这些 id 形成 `custom`），不得把
`academic-research` 当作 `visual_style` id。只有用户明确要求，才启用艺术海报、
奢华、卡通、霓虹、Y2K、拼贴或营销式视觉。

- 默认 16:9。仅院校模板、旧教室设备或用户明确要求时使用 4:3；不得为“传统答辩感”
  自行切换画布。
- 默认白/暖白背景、深海军蓝结构色、冷灰辅助色、青蓝数据色。颜色用于变量、状态、
  组别和层级编码，不用于无意义装饰；同一语义在全稿保持一致。
- 中文优先 `Microsoft YaHei` / `DengXian` 等目标机已安装黑体类字体，拉丁字符优先
  `Arial`，公式优先 `Cambria Math`。不得依赖未确认安装的网字体。
- 在 `1280×720` 画布上，封面标题建议约 `68px`，页标题不得低于 `48px`，正文不得
  低于 `24px`，来源/脚注通常 `16–18px`。院校模板可覆盖；否则内容放不下时应重构、
  拆页或缩短，而不是继续缩字。
- 中文使用全角标点，避免句首出现逗号、句号、顿号、分号、冒号、右括号等禁则字符；
  避免孤行标题、英文单词无意义断裂和中英文标点混用。数字与单位遵循学科惯例。
- 默认禁用渐变、3D 图表、厚重投影、玻璃拟态、营销式圆角卡片墙、装饰性满版图、
  无意义图标和花哨动画。明确模板或用户要求可以覆盖兼容项，但不能降低可读性和证据
  完整性。
- 每页应有可复述的主结论或研究动作。目录、章节页和结束页服务论证节奏；正式答辩
  可保留礼貌性“感谢/请批评指正”，但不能用它替代实质结论。

## 6. 图表、表格、公式与科研图像

- 图表先保证数据映射正确，再设计样式。展示变量名、单位、样本/数据范围、图例或直接
  标注、必要的不确定性和来源；用形状/线型/标签冗余编码，避免只靠颜色区分。
- 表格保留行列语义、单位、缺失值含义、合并关系和脚注。`0`、`—`、`NA` 与“未报告”
  不得互换；文献矩阵只填写来源明确支持的比较项。
- 公式必须来自材料或研究定义，保留符号说明、条件与引用；不得为了“像科研”而添加
  装饰公式。能用 Office Math 保持可编辑时优先使用原生公式。
- 默认不使用图标或 AI 配图。真实实验装置、样本、显微图、遥感图、病例图、截图、
  现场照片和论文图属于证据，应使用可追溯的真实来源并保留必要题注、比例尺和许可。
- AI 图只能作为非证据性的概念示意或背景，且必须在页内醒目标注“概念示意（AI 生成）”；
  不得生成或仿造实验结果、医学影像、显微图、凝胶、电镜图、仪器输出、田野照片、
  调研现场、数据图或论文截图。精确科研示意优先用原生 SVG/形状重绘。

## 7. 完成前学术自检

- 每个核心结论都能追溯到用户材料、稳定 `fact_id`、明确推导或醒目的情景数据标签。
- 题目、研究问题、方法、结果、限制与贡献的措辞彼此一致；没有把计划写成结果。
- 图、表、公式、统计量、单位、样本量和引用均可核对；没有装饰性引用。
- 院校/会议强制字段、章节、顺序、页数或时长约束均已满足。
- 中文断行、标点、英文字体、公式字体、来源字号和投影距离可读性均已检查。
- 备注来源块与页内短引一致；启用音频时遵守纯口语输入边界。
