# Academic Research — Style Specification

> 本文件只规定可复用的学术表达方法与设计默认值，不拥有当前项目的沟通契约、院校身份、页序、页面几何或 SVG 原型。院校或会议模板及用户明确要求始终优先。

## I. Style Overview

| Property | Value |
|---|---|
| Style Name | Jadense 学术研究报告 |
| Best Fit | 中国高校开题、中期考核、预答辩、正式答辩、学术会议、组会、项目汇报与基金评审 |
| Reusable Intent | 让具备专业背景且持审慎态度的听众，能够沿“问题—证据—方法—结果—边界”审查论证是否成立 |
| Required Project Metadata | 项目级 Design Spec 必须记录：报告类型、学科、培养阶段、院校/会议、听众、时长、强制章节、引用格式、证据状态；本 Style 只规定字段要求，不预填项目值 |
| Sources | 基于 `ppt-master` 4.7.0 的 Style 骨架，由 Jadense 面向中文学术报告规范化；不代表任何院校或会议的官方模板 |

## II. Communication Method

- **Preferred Mode**: custom
- **Mode References**: instructional, pyramid
- **Mode Behavior**: 按学术评议能够复核的顺序推进：研究问题与价值、相关工作与缺口、研究问题或假设、方法与数据、结果或预期验证、局限与计划、结论与待评议问题。页内采用结论可追溯的金字塔纪律，但不得为了“结论先行”把尚未观察到的结果写成既成事实；开题中的预期、方案与演示数据必须明确标注。
- **Argument Flow**: 先界定问题和术语，再说明现有工作已经解决什么、仍缺什么；随后给出可复现的方法、数据来源和评价设计；结果页先陈述观察，再给出受证据约束的解释；最后说明有效性威胁、贡献边界和后续工作。开题、中期和答辩可压缩中段，但不得删除证据来源、研究边界与真实性标记。
- **Page Message Discipline**: 每页只承担一个研究判断、一个方法环节或一组可比结果。页标题优先写“本页建立了什么”，避免只写“研究背景”“实验结果”等空泛章节名；关键结论必须与支撑它的图、表、公式或引用同页出现。
- **Claim Discipline**: 严格区分事实、观察、统计结果、推断、假设、计划和猜测。不得虚构论文、作者、数据、样本量、显著性、置信区间或实验结论；未经验证的数字使用“演示数据”“预期”“待验证”醒目标注。因果、相关与机制解释必须分别措辞，负结果与局限不得弱化或藏入附录。

## III. Page Role Vocabulary

| Role | Communication Job | Evidence Obligation | Composition Tendency |
|---|---|---|---|
| 研究问题 | 明确研究对象、条件、变量和待回答问题 | 用可核验文献、数据或现实约束建立问题，不以口号代替缺口 | 问题句占主导，一页一个核心问题 |
| 相关工作定位 | 说明已有方法的能力边界及本研究位置 | 准确描述他人成果并逐页短引，比较维度一致 | 优先矩阵、谱系或机制对照，不做作者名单堆砌 |
| 研究假设 / RQ | 将问题转为可证伪、可评价的命题 | 给出操作化定义、判定标准与不成立条件 | 假设与对应指标同区呈现 |
| 贡献边界 | 说明本工作新增内容以及明确不声称的内容 | 每项贡献映射到可交付物或结果证据 | 与“非贡献 / 尚未覆盖”并列，避免夸张 |
| 方法与技术路线 | 使研究设计可判断、可复现 | 交代数据、输入输出、关键参数、控制变量和选择理由 | 一条主流程；分支只保留会影响结论的部分 |
| 数据与材料 | 说明研究建立在哪些材料之上 | 标注来源、规模、采集时间、纳排标准、授权与已知偏差 | 关键事实可扫读，偏差不放在不可见脚注中 |
| 结果 | 陈述实际观察 | 显示样本量、单位、误差或区间；演示数据必须醒目标注 | 图表主导，旁侧写可由图表直接核验的阅读句 |
| 对比与消融 | 解释改进来自哪里、相对谁成立 | 公平基线、同一条件、调参说明与不确定性 | 共享坐标与稳定颜色映射，突出决定性差异 |
| 局限与有效性威胁 | 说明结论不能外推到哪里 | 指出真实威胁、可能方向和缓解计划 | 作为正式页面或等价显著区域，不作仪式化尾注 |
| 计划与里程碑 | 将未完成工作转为可检查安排 | 明确依赖、验收证据、风险和缓冲 | 时间轴或表格为主，不用装饰性甘特图 |
| 结论与待评议问题 | 回答开头问题并邀请针对性反馈 | 只重述证据支持的结论；列出希望评委判断的问题 | 与研究问题页形成可见闭环 |
| 附录 | 支撑答疑与复核 | 保留完整参数、推导、补充结果、伦理与来源 | 可高密度，但必须可检索、可读 |

## IV. Evidence & Data Expression

- **Argument Trace**: 每个结论映射到结果，每个结果映射到方法和数据，每个外部事实映射到可解析来源。链条缺失时直接写“证据待补 / 待验证”，不得用叙述填补。
- **Charts**: 优先使用原生可编辑图表；估计量显示样本量及误差或区间，并说明区间含义。比较图共享尺度，颜色与方法映射全稿固定；不得隐瞒异常值、无说明截断坐标轴或选择性展示子集。图题写观察，解释另行表述。
- **Tables**: 用于相关工作矩阵、数据集特征、参数、定量比较、风险和进度。单位与精度一致；外部报告值、复现实验值、演示值分别标记；强调“最好”前说明比较口径。
- **Sources**: 论文、数据、图、方法与关键事实在出现页给出简短引用，讲者备注或参考页给出可解析完整来源。改绘、翻译或裁剪他人图形时标注“改编自”；不确定来源不得猜测补全。
- **Native Editability**: PPT 中承载核心数字的图表与表格优先保持 Office 原生可编辑；分析流水线生成的科研图像按原始保真度导入，不手工重绘为不同数据。公式优先使用 Office Math 或可核验的矢量公式。

## V. Visual System Defaults

- **Preferred Visual Style**: swiss-minimal
- **Composition**: 16:9（1280×720）为默认；只有用户明确说明旧教室或传统 4:3 投影兼容时才选择 4:3。学术自动视觉风格白名单为 `swiss-minimal`、`editorial`、`data-journalism`、`blueprint`，当前首选 `swiss-minimal`；每页围绕一个主要证据对象或判断组织，稳定页标题、来源和页码位置；真实多条件比较才使用多面板。
- **Density**: 正文与结果页只保留支撑一个判断的信息；完整条件进入附录。高密度不是缩小字号的理由，信息超出时拆页或移入附录。
- **Decoration**: 实质上无装饰。允许细分隔线、浅色分区和必要标注；禁止渐变、3D 图表、玻璃拟态、强投影、营销式圆角卡片阵列、装饰性满版图和花哨动画。用户显式指定且不损害证据阅读时，才可偏离。
- **Color Behavior**: 默认白或暖白背景，深海军蓝承担结构，冷灰承担次级文本与分隔，青蓝承担数据强调；颜色只编码已声明的变量或状态，同一实体全稿同色。不得用院校徽标色冒充已确认身份，也不得用红绿作为唯一类别区分。
- **Typography Character**: 简体中文优先 `Microsoft YaHei`（微软雅黑）或 `DengXian`（等线），拉丁字符优先 `Arial`，公式优先 `Cambria Math`；字体不可用时使用同类别 Office 安全回退。按 1280×720，封面标题约 68px、普通页标题至少 48px、正文至少 24px、来源与脚注 16–18px；图表标签不得继承论文印刷小字号。

## VI. Image & Icon Direction

- **Preferred Image Rendering**: minimalist-swiss
- **Image Usage**: 默认 `none`；如用户提供科研图片、实验装置图、现场照片或院校模板资产，则优先 `provided`。只有用户明确需要且内容确需概念示意时才启用 `ai`。AI 图不得充当实验结果、数据、显微图、临床影像、现场照片或任何真实性证据。
- **Image Treatment**: 科研图片保留原貌，仅做已声明的裁剪、亮度或对比度调整；需要尺度时给出比例尺，标明条件、来源、日期及处理。AI 概念图必须在页面或图注明确标注“AI 生成概念示意”，不得仿造实验或观测图像。
- **Icon Treatment**: 默认 `none`。图标仅可在反复出现的步骤类型、仪器类别或状态标记中使用，且必须有稳定语义；不得用图标替代数量、证据或学术概念，不使用图标墙或院校装饰。

## VII. Review Focus
<!-- visual-review-trigger: explicit-user-only -->
> 仅当用户显式启动视觉复核时应用本节；本节本身不得触发视觉复核阶段。

- 院校或会议模板、页数、时长和必需章节是否得到遵守。
- 每个结论是否能在同页证据或明确来源中核验；演示、预期与真实结果是否醒目区分。
- 中文换行是否避免行首标点、孤立单位和不恰当中英文间距；公式、变量与单位是否一致。
- 标题、正文、图例、坐标轴、来源和脚注在教室后排观看距离下是否仍可读。
- 不确定性、样本量、单位和坐标尺度是否完整；色彩映射是否全稿一致并兼容灰度与色觉差异。
- 是否没有渐变、3D、营销卡片、装饰性满版图或花哨动画干扰论证。
- 引用是否在出现页可解析，备注是否保留完整 `[Sources]`，局限是否占有真实可见空间。
