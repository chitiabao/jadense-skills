# 智能翻译与导读指南 — jadense-scholar-search

本文件是 `jadense-scholar-search` 技能的**智能翻译 + 智能导读**参考。在选取出有价值的文献（可先用 `--enrich` 补齐缺失摘要）之后，由调用方大模型对**标题 + 摘要**做双语呈现与智能翻译，并为每篇撰写推荐理由与导读要点。翻译与导读由模型编排层完成，核心库不做翻译。

## 1. 双语呈现约定（交付硬性要求）

交付结果一律保留**中英双语**，符合以下布局：

- **标题**：中文翻译与英文原文**同时可见**。中文为主标题，英文原文紧随其后（如副标题/括号），二者同行或上下紧邻呈现。
- **摘要**：中文翻译与英文原文通过 **tabs 切换**呈现，默认显示中文翻译，用户可切换到英文原文。不把两段长摘要同时平铺。
- 除标题与摘要外的元数据（期刊、作者、DOI、URL、日期、被引数）**保持原文**，不翻译。

## 2. 翻译范围与规则

**范围**：仅 `title` 与 `abstract` 两字段。

**通用规则**

- 保留不译：DOI、URL、作者名、机构名、数字、日期、单位、化学式、基因符号、蛋白质名、缩写（如 LLM、CNN、BERT）、代码标识、版本号。
- 关键术语首次出现用「中文（English）」双语，其后统一用中文；行业通用缩写保留原文。
- 学术中文、忠实原文：不做扩写、删减或意译发挥；不引入机翻腔（如"当今""值得注意的是"等冗余）。
- 忠于作者原意：不确定的表述保守直译，不臆造文献没有的结论。
- 字段感知：只翻译标题与摘要正文，不要把 DOI/URL/期刊名强行音译。

**标题翻译**：译文凝练、可独立成句；保持与原文一致的语序主次。

**摘要翻译**：以段落为单位整体翻译，保持逻辑连贯；专业缩写在首次出现时以「中文（English）」标注，其后沿用原文缩写。

## 3. 智能导读（推荐理由 + 导读要点）

为每篇被推荐的文献产出以下结构化导读，字段缺失时如实说明，不臆造。

**推荐理由（≤4 行）**：从以下维度给出简明理由，注明依据取自 `SearchResponse` 的真实字段：

- 相关性：与查询主题的贴合程度（`relevanceScore` / 标题语义）。
- 新颖性：发表年份、是否近期工作。
- 影响力：`citationCount`、来源期刊/会议。
- 方法学价值：该文对理解主题的独特贡献。

**导读要点（1–3 条）**：给出此类读者阅读时应重点看的章节或关注点，例如"第 3 节的实验设计""方法部分的消融实验""结论对工程部署的启示"。

**可选：总体导读**。当交付多篇文献时，可在页首给一段 2–4 行的总体导读，概括本批文献的主题脉络与取舍建议（按"先读哪篇、再读哪篇"）。

## 4. 工作流

1. 运行 `--enrich`（或库调用 `enrich: true`）补齐缺失摘要，得到结构完整的 `SearchResponse`。
2. 按第 2 节规则将每篇的标题 + 摘要翻译为用户语言。
3. 按第 3 节为每篇撰写推荐理由与导读要点。
4. 按第 1 节双语约定与 `references/html-result-guide.md` 模板组装交付页面。

## 5. 约束

- 不臆造：翻译忠于原文，导读理由基于真实字段，缺失字段如实标注。
- 双语：标题中英并存、摘要 tabs 切换是交付硬性要求。
- 元数据保真：DOI/URL/作者/期刊/日期/被引保持原文。
