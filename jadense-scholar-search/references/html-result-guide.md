# HTML Result Guide — jadense-scholar-search

本文件是 `jadense-scholar-search` 技能的 **HTML 结果交付**参考。当需要把文献检索结果以可视化、可分享、可打印的网页形式交付给用户时，参考本文件的风格与内嵌模板生成一份**自包含、零外部依赖**的 HTML 结果页。

风格基于 Claude.com 的暖奶油色编辑排版设计系统（`DESIGN` 文档），在"零外部依赖"约束下做了字体替代。

## 1. 何时交付 HTML

- 用户显式要求"网页 / 可视化 / 精美交付 / 报告页 / 一键保存成文件"。
- 交付物需要**可分享、可打印**，或包含**多篇对比文献**。
- 左侧摘要、条目卡片、诊断信息的分层呈现能显著提升阅读体验。

反之，简单问答或需要把原文粘贴进聊天的场景，继续使用 `--format markdown` 或纯文本。

## 2. 风格参考（零外部依赖版）

### 2.1 画布与色彩

锚定**暖奶油画布**，不用纯白或冷灰白。主强调色为**珊瑚色**，稀缺使用。

|---|---|---|
| `--canvas` | `#faf9f5` | 页面底色调和默认背景 |
| `--ink` | `#141413` | 标题与主文字（暖墨，非纯黑） |
| `--body` | `#3d3d3a` | 正文默认颜色 |
| `--body-strong` | `#252523` | 强调段落、引言 |
| `--muted` | `#6c6a64` | 次要文字、标签、来源 |
| `--muted-soft` | `#8e8b82` | 极弱文字（仅大字号/非正文时用） |
| `--hairline` | `#e6dfd8` | 1px 分隔线 / 边框 |

### 2.2 表面节奏（三表面交替）

1. **奶油画布** `--canvas` — 默认正文地板。
2. **浅奶油卡片** `--surface-card` — 文献条目卡片。
3. **深海军表面** `--surface-dark` — 顶部摘要条、页脚、诊断/警告区块。

深浅交替带来页面节奏；不要连续两块用同一表面模式。

### 2.3 字体（零外部依赖替代）

Copernicus / StyreneB 为授权字体，无法随自包含 HTML 加载，按下述浏览器字体栈替代：

- **显示 / 标题**：`Cormorant Garamond, Georgia, "Times New Roman", serif` — weight **400**（不加粗）、负字距 `-0.02em`。serif 是品牌气质。
- **正文**：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` — humanist sans，weight 400，标签/强调用 500。
- **代码 / DOI / 元数据**：`JetBrains Mono, ui-monospace, SFMono-Regular, Consolas, monospace`。

### 2.4 圆角与阴影

- 按钮 / 输入：`8px`；卡片：`12px`；徽章 pill：`9999px`。
- **阴影极简**：以"色块对比"制造层级。如确需，用 `0 1px 3px rgba(20, 20, 19, 0.08)`。

### 2.5 Do's / Don'ts

**Do**
- 锚定奶油画布；正文在 `--canvas` 上用 `--ink/--body`，对比度 ≥ 4.5:1。
- 珊瑚稀缺：只用于关键徽章、统计数字、内联链接、CTA。
- 深浅表面交替制造节奏。
- 显示层级用**字号 + 字重**而非换字体族。
- 保留每条记录的 DOI / URL / 外部身份，不臆造缺失字段。

**Don't**
- 不用纯白 `#ffffff` 或冷灰当页面主背景。
- 不把珊瑚铺满整个页面。
- 不用 Arial / Helvetica（破坏 humanist 气质）。
- 不加粗 serif 标题（weight 400 是规则）。
- 不给无 DOI 的 Google Scholar 记录伪造稳定身份。

## 4. 使用步骤

1. **先补全**：需要完整摘要时，先运行 `--enrich`（或库调用 `enrich: true`）补齐缺失摘要，再进入翻译与组装。
2. **翻译与导读**：按 `references/translation-guide.md` 将每篇标题 + 摘要智能翻译，并撰写推荐理由与导读要点。标题保留中英双语；摘要用 tabs 切换（默认中文）。
3. **复制**上方整段 ```html 代码块。
4. **替换占位符**：
   - 将 `SearchResponse.queryPlan` 映射到摘要条（`{{QUERY}}`、`{{PROVIDERS}}`、`{{LIMIT}}`、`{{DATE_RANGE}}`、`{{TOTAL_HITS}}`、`{{MERGED}}`、`{{DATE_REJECTED}}`、`{{DIAG_COUNT}}`）。
   - 将 `results[]` 逐条渲染为 `<article class="paper">`：双语标题（`{{TITLE_ZH}}` 主 + `{{TITLE_EN}}` 原文）、`{{RATIONALE}}` 与 `{{READING_POINT_*}}` 导读、`{{ABSTRACT_ZH}}` / `{{ABSTRACT_EN}}` 摘要 tabs、`{{AUTHORS}}`、`{{PUBLISHED_DATE}}`、`{{VENUE}}`、`{{CITATION_COUNT}}`、`{{PROVIDER}}`、`{{DOI}}`、`{{EXTERNAL_ID}}`。`authors` 用 `displayName` 以 `; ` 连接；`{{EXTERNAL_ID}}` 需保证每个卡片内 `abs-zh-*` / `abs-en-*` 的 `id` 唯一。
   - 在 `Overview` 表格中为每条记录加一行 `{{TABLE_ROWS}}`；长 URL 放进 `.url` 单元格。
   - 有 `diagnostics[]` 时渲染诊断区块，按 `severity` 用 `info/warning/error` 类。
   - 页脚 `{{SOURCE_ITEMS}}` 为每篇文献生成一条 `<li>`（含可点击的 DOI/URL 链接）。
5. **字段缺失**：`publishedDate / venue / doi / url / abstract / citationCount` 为 `null` 时显示 `Unknown` 或省略对应行，**不要臆造**。无摘要时省略摘要 tabs，仅显示已有的摘要语言。Google Scholar 无 DOI 记录不伪造稳定身份，仅显示来源与展示层元数据。
6. **校验**：确认文件为单一 `.html`、无外链、`lang` 与内容匹配、标题层级连续、每个摘要 tabs 可正常切换、移动端单列、长 URL 不溢出。
7. **交付**：将 HTML 保存为 `.html` 文件并给出文件路径。

## 5. 硬性约束

- **双语交付**：标题中英并存、摘要 tabs 切换（默认中文）为硬性要求；元数据（DOI/URL/作者/期刊/日期/被引）保持原文。
- **零外部依赖**：无 CDN、无外链字体、无外部 JS。所有样式内联；仅有内联的 tabs 切换脚本。
- **CSS 变量**：颜色一律走 `:root` 变量，不在规则里硬编码十六进制。
- **WCAG AA**：正文/卡片文字与背景对比度 ≥ 4.5:1；语义化标签；标题层级连续；`:focus-visible` 高亮；`target="_blank"` 加 `rel="noopener"`；tabs 用 `role="tablist"/"tab"/"tabpanel"` 与 `tabindex` 语义。
- **响应式**：容器 `max-width: 1200px`；卡片与表格在 ≤768px 单列/横向滚动；`@media print` 与 `prefers-reduced-motion` 已内置。
